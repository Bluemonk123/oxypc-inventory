Location Mapping —
These locations and their contact numbers are added to every selected account. A location the account already has (same address, city and state) is kept, not duplicated.
{% set loc = None %} {% include "crm/contacts/_location_block.html" %}

Columns: gstin, company_name, location_address, location_city, location_state, location_email, location_contact_role, location_contact_name, location_contact_phone, location_contact_email.

Each row adds one contact to one location of an existing account (found by gstin, else company_name). Repeat a location on more rows to add more contacts there. Accounts are never created here.
