Bulk Upload Accounts & Calls

Columns are matched by header name (case-insensitive), so column order does not matter. Each row is matched to an existing account by phone or company_name; anything unmatched is created. Rows that fail are skipped and listed — one bad row never aborts the file.

  • Row with account columns and call columns → account created/updated, call logged
  • Row with account columns only → account created/updated, no call logged

This accepts the plain Bulk Upload CSV columns unchanged, so it also covers straightforward account-only imports.
